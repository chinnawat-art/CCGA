Discord Webhook

ชื่อผู้บันทึกประจำเครื่องนี้

เครื่องใครเครื่องมัน — ตั้งครั้งเดียว แอปจะกรอกให้ทุกครั้ง และชื่อนี้จะขึ้นเป็นชื่อผู้โพสต์ในห้อง Discord

วิธีสร้าง Webhook (ทำครั้งเดียว ~2 นาที)

  1. เปิดแอป Discord → สร้าง Server ใหม่ (ปุ่ม + ด้านซ้าย → "Create My Own")
  2. สร้างห้อง (channel) ชื่อเช่น #บันทึกส่งของ
  3. กดรูป ⚙️ Edit Channel ที่ห้องนั้น → เมนู Integrations → Webhooks → New Webhook
  4. กด Copy Webhook URL แล้วเอามาวางในช่องด้านบน → กดบันทึก → กดทดสอบส่ง
⚠️ ลิงก์ Webhook เหมือนกุญแจห้อง — ใครมีลิงก์ก็โพสต์เข้าห้องได้ อย่าแชร์สาธารณะ
